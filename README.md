# المترجم الفوري المستقل - Offline Windows Translator

برنامج ترجمة احترافي وخفيف لنظام Windows يعمل **بدون اتصال بالإنترنت بنسبة 100%** بالاعتماد على محرك **CTranslate2** ونموذج **NLLB-200 Distilled 600M (INT8)** مع دعم كامل للغتين العربية والإنجليزية في كلا الاتجاهين.

---

## 🌟 أبرز المميزات

1. **يعمل دون اتصال 100% (Offline-First):**
   - لا يتم إرسال أي نص أو ترجمة أو إحصائيات إلى أي خادم خارجي نهائياً.
   - الاتصال بالإنترنت يُستخدم فقط عند رغبة المستخدم الصريحة في تنزيل النموذج من داخل البرنامج.

2. **محرك CTranslate2 بدقة INT8:**
   - سرعة فائقة واستهلاك منخفض للذاكرة العشوائية RAM (~1 جيجابايت) عبر المعالج CPU العادي دون الحاجة لبطاقة رسوميات متقدمة.

3. **نافذة عائمة ذكية (Smart Floating Window):**
   - تظهر بالقرب من مؤشر الفأرة تلقائياً عند الضغط على الاختصار العام.
   - تغيير تلقائي في الحجم حسب طول النص بحد أقصى ثلث مساحة الشاشة.
   - البقاء داخل حدود الشاشة وتمرير سلس للنصوص الطويلة وتثبيت في المقدمة (Pin).

4. **اختصار عام مدمج بنظام Windows:**
   - تسجيل الاختصار (`Ctrl+Alt+T` افتراضياً) عبر `RegisterHotKey` من واجهات Win32 مباشرة دون مكتبات ثقيلة.
   - التقاط النص المحدد من أي برنامج في Windows واستعادة محتوى الحافظة بأمان.

5. **إدارة النماذج الذكية:**
   - تنزيل النموذج المعتمد مباشرة من داخل البرنامج مع دعم الاستكمال (Resume) وعرض السرعة والوقت المتبقي وفحص التجزئة الرقمية (SHA256).
   - إمكانية تحديد مجلد نموذج موجود مسبقاً على الجهاز والتحقق من صحته.

6. **وضع محمول حقيقي (Portable Mode):**
   - تُحفظ الإعدادات وقاعدة البيانات وسجل الترجمات والنماذج داخل مجلد البرنامج.
   - لا يُجبر المستخدم على استخدام `AppData` أو `Registry`.

7. **قراءة النصوص صوتياً (Text-To-Speech):**
   - دعم القراءة الصوتية الإنجليزية محلياً عبر محرك Windows SAPI المدمج دون إنترنت، مع التحكم في الصوت والسرعة ومستوى الصوت.

8. **سجل ترجمة محلي (SQLite):**
   - بحث فوري، تصفية حسب التاريخ واللغة، وتصدير واستيراد بصيغتي CSV و TXT.

9. **ترجمة المستندات:**
   - معالجة ملفات النصوص `TXT` و Markdown `MD` و `CSV` تدريجياً وحفظ النتيجة في ملف جديد كلياً دون الكتابة فوق الأصل.

## 🚀 التشغيل من المصدر (Development)

1. **تثبيت المتطلبات التشغيلية:**
```bash
pip install -r requirements.txt
```

2. **تشغيل التطبيق:**
```bash
python -m Localex
```
أو:
```bash
python src/Localex/main.py
```

---

## 🛠 بناء نسخة Windows EXE المستقلة (Build)

لبناء النسخة التنفيذية المحمولة OneDir باستخدام PyInstaller مع ضغطها في ملف ZIP:

```powershell
.\build.ps1
```

سيتم إنشاء مجلد التشغيل المستقل في `dist\Localex\` وملف `Localex_Portable_v1.0.0.zip`.
